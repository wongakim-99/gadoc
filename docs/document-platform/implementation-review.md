# 문서 화면 구현 확인 — 2026-10-26

노션에 익숙한 사용자에게 자연스러운 문서 작업 공간을 제공하기 위한 첫 UI 변경이다. 전체 노션 기능 구현 또는 동등성 검증 완료가 아니다.

## 직접 확인

기존 로컬 서버·MongoDB·스토리지 프로필이 준비된 환경에서:

```powershell
npx --yes yarn@1.22.22 install --frozen-lockfile
npx --yes yarn@1.22.22 dev:stack:profile
```

`http://localhost:3002`에서 로그인 → 팀 → 문서/위키 → 문서를 연다. 프로필 설정은 [runtime-profiles.md](../runtime-profiles.md)를 참고한다. 위 스크린샷의 `review-team`은 테스트 전용 식별자로 실제 서버 계정이나 URL이 아니다.

1. 상단 탐색 버튼으로 문서 트리를 열고 검색·펼치기·페이지 이동을 확인한다.
2. 상단 경로에서 부모 페이지로 이동한다. 접근 가능한 문서 목록만 경로에 사용한다.
3. 편집을 누르고 제목과 본문을 작성한다. 빈 줄에서 `/`를 입력하면 한국어 블록 메뉴가 열린다.
4. 저장 또는 Ctrl/⌘+S로 저장한다. 자동 저장은 아직 아니다.
5. 댓글·이력 버튼으로 보조 패널을 열거나 닫는다. 전체 너비 버튼으로 본문 폭을 변경한다.

## 변경 범위

- 페이지 중심 본문, 중립적인 어두운 문서 배경, 상단 도구막대·경로, 접을 수 있는 문서 트리와 댓글/이력.
- BlockNote의 공식 Mantine UI 연결: 슬래시 메뉴·서식/블록 도구 UI에 필요한 컴포넌트 제공. 한국어 사전 사용.
- 기존 문서 API와 연결. 편집 후 저장은 JSON 블록 형식으로 통일하며 기존 HTML/plain은 편집기에서 변환된다. 원문 HTML의 모든 서식 보존은 보장하지 않으므로 중요 가져오기 문서는 별도 회귀 검증이 필요하다.
- JSON 문서 파일 첨부 시 HTML 문자열이 값으로 전달되던 경로 수정.
- 저장 중 중복 요청·편집 차단, 저장 오류 표시와 내용 유지, 빈 제목 검사, 에디터 준비 전 저장 차단, 잘못된 JSON 덮어쓰기 차단.
- 편집 중 새로고침/창 닫기와 일반 링크 클릭 경고. 브라우저 뒤로가기·프로그램 방식 이동 전체에 대한 차단이나 로컬 초안 복구는 아직 미구현이다.
- 문서 로딩 오류 표시. 상위 경로 탐색은 누락/순환 참조에서 종료한다.

## 검증

- 웹 TypeScript 검사 통과.
- 웹 단위 테스트70개 통과: 상위 경로 순서·접근 불가 부모·순환 참조 시험 포함.
- Playwright3개 통과: 탐색/한국어 슬래시 메뉴/저장 실패·재시도·새로고침, 잘못된 JSON 저장 차단, 모바일 읽기 전용·가로 넘침 검사.
- 브라우저 시험은 API mocking을 사용한다. 실제 로그인·DB 저장·권한 집행·파일 스토리지 업로드는 이번 시험에서 검증하지 않았다.
- 새로 추가한 스타일과 메뉴를 포함한 실제 브라우저 캡처를 검토했다. 프로덕션 빌드·배포는 수행하지 않았다.

재현(웹 dev 서버를 먼저 실행):

```powershell
$env:SLACORD_E2E_BASE_URL='http://127.0.0.1:3002'
node node_modules/playwright/cli.js test tests/e2e/document-workspace.e2e.spec.ts
```

## 남은 제품 범위

자동 저장·초안 복구·충돌 제어·실시간 공동 편집, 아이콘/커버/페이지 레이아웃 영속 설정, DB 속성/뷰/관계/롤업/수식, 권한 상속, 자동화/확장, 실제 서버 E2E는 후속 작업이다. 기존 독립 `document-core`는 아직 웹·서버에 연결하지 않았다. [전체 분석](../notion-analysis/README.md)의 미확인 영역도 계속 유지한다.
