# 문서 Mermaid 블록

`/mermaid` 또는 `/다이어그램`으로 기본 다이어그램을 즉시 삽입한다. 코드/미리보기 전환, 50–200% 확대, SVG 다운로드를 지원한다. 코드는 기존 문서 공동 편집 및 자동 저장 경로로 보존되며 읽기 전용 사용자는 보기와 내보내기만 가능하다.

Mermaid 12.2.0을 지연 로드하고 strict 모드로 렌더링한다. 결과는 실행 가능한 inline HTML이 아닌 이미지로 표시한다. 10,000자/200줄/100 edge 제한을 적용하고 설정 지시문·외부 리소스·HTML·클릭 명령을 차단한다. 이미지 참조 등 임의 외부 네트워크 사용은 지원하지 않는다. 렌더링 실패 시 코드 원문을 지우지 않는다. 렌더링은 직렬 처리하며 이전 비동기 결과가 새 코드의 미리보기를 덮어쓰지 않도록 한다.

로컬 검증: 슬래시 생성, 코드 편집/미리보기, 서버 저장과 새로고침, 두 사용자 간 편집 반영, guest 읽기 전용, 위험한 링크 명령 차단과 복구, 확대와 실제 SVG 다운로드. 빌드/타입 통과. 전체 Mermaid 문법 및 Notion 전체 기능 동등성을 의미하지 않는다.

기준: https://mermaid.js.org/config/usage.html
