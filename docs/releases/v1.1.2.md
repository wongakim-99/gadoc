# GaDoc v1.1.2

## 데스크톱 배포

- macOS 앱·DMG·ZIP의 Developer ID 서명, Apple 공증 및 Gatekeeper 검증을 릴리즈 필수 조건으로 적용함.
- 설치 파일별 SHA256과 실제 OS 검증 기록을 `desktop-verification.json`으로 함께 제공함.
- macOS는 DMG 수동 설치 정책을 유지하며, 기존 미서명 설치본의 자동 전환을 약속하지 않음.
- Windows는 실제 Authenticode 결과를 표시하며 미서명 파일의 SmartScreen 안내를 유지함.
- 기존 앱 ID·설정·로그인 프로필 호환성을 유지함.

## 사용성

- 새 설치본은 `https://gadoc.kr`로 연결하며 구 도메인은 전환 기간에만 유지함.
- 다운로드 목록 API 장애·오프라인 빌드에서도 검증된 설치 링크와 해시를 유지함.
- 신뢰한 서비스의 클립보드 쓰기를 허용하고 읽기 권한은 계속 차단함.
- 웹 문서의 배치·링크 선택과 공유 링크 복사 오류 개선을 반영함.

## 검증 기준

공개 태그의 실제 빌드가 서명·공증 검증을 모두 통과해야 설치 파일을 발행함.
사전 리허설 결과만으로 새 버전의 공증을 완료했다고 표시하지 않음.
RN 모바일 앱은 별도 검증·스토어 심사 대상이며 이 데스크톱 릴리즈에 포함하지 않음.
