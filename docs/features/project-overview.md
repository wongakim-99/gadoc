# 업무별 홈 현황

홈은 선택한 업무 그룹과 전체 그룹을 전환하며 실제 접근 가능한 이슈/문서/채널 데이터를 보여준다. 가짜 온라인 인원이나 샘플 수치를 만들지 않는다. 기존 권한 검사를 수행하는 API 응답을 사용하며 API 실패를 0건으로 표시하지 않는다.

- 이슈 상태별 수치와 내 담당만 보기. 카드 클릭 시 업무·상태·담당자·기간 조건을 이슈 목록에 전달한다.
- 전체 기간/최근 7일·30일 변경 기준. 기간은 수정 시각으로 집계하며 이슈 목록에서 별도로 해제할 수 있다.
- 미완료 내 담당 작업, 업무의 문서 루트 및 하위 페이지 중 최근 수정 문서, 실제 마지막 메시지 시각에 따른 최근 채널 대화.
- DB 행 페이지는 문서 목록에 반복 노출하지 않는다. 비공개 문서 및 채널은 기존 서버 접근 제어를 따른다.
- 전체 그룹에서는 워크스페이스 멤버를, 선택 업무에서는 실제 이슈 담당자를 표시한다. 별도 프로젝트 멤버십 모델이 있는 것처럼 표시하지 않는다.
- 최근 대화가 없더라도 기존 채널 진입 링크를 제공하며, 채널이 전혀 없으면 작성 권한 사용자에게 생성 진입을 제공한다.
- 조회 오류, 데이터 없는 상태, 그룹 제거, 좁은 화면을 구분한다. 최신 조회 시각과 새로고침을 제공하고 관련 변경 이벤트를 묶어서 재조회한다.

검증: 실제 API E2E에서 그룹별 수치·담당자·기간 및 목록 이동, 그룹 선택 유지, 권한별 비공개 문서 제외, 모바일 가로 넘침, 실패 후 0건 오표시 방지와 복구를 검증했다. 기존 이슈 필터 2개와 새 워크스페이스 채널 이동 회귀도 통과했다.
