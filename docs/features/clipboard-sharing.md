# 공유 링크와 복사

운영 도메인 `slacord.cloud`, `www.slacord.cloud`, `www.gadoc.kr`에서 생성하는 초대·데이터베이스 공유 링크는 `https://gadoc.kr`를 사용합니다. 초대 코드·역할·만료·사용 횟수는 변경하지 않습니다. 개발/자체 호스팅 주소는 유지하며 로그인 쿠키와 소켓은 현재 호스트에 연결합니다.

초대 링크 목록은 활성 링크 유무와 독립적으로 각 코드의 전체 주소를 생성합니다. 비활성 링크를 활성 링크로 취급하거나 빈 값을 복사하지 않습니다. 활성 링크가 없으면 활성 링크 복사와 QR은 비활성화됩니다.

복사는 비동기 Clipboard API를 먼저 사용하고, 거부되거나 API가 없으면 사용자 선택 기반 복사를 시도합니다. 둘 다 실패하면 성공으로 표시하지 않습니다. 초대/DB 복사 버튼은 오류와 선택 가능한 원문을 제공하며, MCP 설정은 현재 표시된 원문을 수동 복사하도록 안내합니다. 클립보드 내용을 읽거나 전송하지 않습니다.

Electron에서는 신뢰된 앱 도메인의 `clipboard-sanitized-write`만 추가로 허용합니다. 클립보드 읽기·과거 동기 읽기·외부 도메인은 계속 차단합니다. 이 네이티브 권한 변경은 새 설치 파일에 포함되어야 적용됩니다. 기존 설치 앱에 웹 대체 처리가 동작하는지와 새 설치 파일 배포 여부를 별도로 확인해야 합니다.
