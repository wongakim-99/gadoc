# GaDoc Sans 사용 안내

GaDoc Sans는 로고 시안의 인상을 실제 한글 서비스에 이어 쓰기 위해 만든 파생 서체입니다.
시안은 이미지로 생성되었으며, 그때 지정된 원본 폰트 파일은 없습니다. 시안의 `g a d o c` 다섯 글자를 재구성하고, Fredoka를 조정한 영문과 LINE Seed 기반 한글을 함께 담았습니다.

## 구성과 지원 범위

- **Regular 400 / Bold 700:** 실제로 서로 다른 두 굵기입니다.
- **TTF:** 컴퓨터에 설치해 디자인·문서 작업에 사용합니다.
- **WOFF2:** 웹사이트에서 직접 호스팅해 사용합니다.
- **한글:** 현대 한글 완성형 11,172자를 포함합니다. 영문·숫자와 함께 사용할 수 있습니다.
- 500·600은 별도로 제작한 굵기가 아닙니다. 적용할 때는 400 또는 700을 지정하세요.
- 옛한글·한자·모든 기호·이모지 전체를 지원한다는 의미는 아닙니다. 포함되지 않은 문자는 지정한 대체 글꼴로 표시될 수 있습니다.

## 먼저 미리보기

1. ZIP을 폴더 전체로 압축 해제합니다.
2. 같은 폴더의 `preview.html`을 브라우저에서 엽니다.
3. 상단에 **실제 WOFF2 로드 완료 · 400 / 700**이 표시되는지 확인합니다.
4. 밝은 화면·어두운 화면, 본문 14·16·18px, 400·700 굵기를 바꿔 봅니다.
5. 직접 입력 영역에 실제 서비스의 메뉴와 문장을 넣어 확인합니다.

견본은 두 WOFF2 파일이 모두 로드된 뒤 표시됩니다. 로드에 실패하면 대체 글꼴을 견본으로 보여주는 대신 오류를 표시합니다.
브라우저가 로컬 폰트 파일을 차단한다면, Python이 설치된 환경에서 압축을 푼 폴더를 기준으로 아래 명령을 실행하고 표시한 주소를 엽니다.

~~~bash
python -m http.server 8000 --bind 127.0.0.1
~~~

주소: `http://127.0.0.1:8000/preview.html`
미리보기는 외부 라이브러리를 요청하지 않으며, 입력한 문장을 전송하거나 저장하지 않습니다.

## 컴퓨터에 설치

`fonts/GaDocSans-Regular.ttf`와 `fonts/GaDocSans-Bold.ttf`를 설치하세요.

- **Windows:** 두 TTF 파일을 각각 열고 설치 버튼을 누릅니다.
- **macOS:** 두 TTF 파일을 각각 열어 서체 관리자에서 설치합니다.
- 사용 중이던 디자인·문서 앱을 다시 열고 **GaDoc Sans**를 선택합니다.
- 이전 제작본을 이미 설치했다면 기존 버전과 이름이 충돌하지 않도록 해당 버전을 정리한 뒤 새 파일을 설치하세요.

## 웹사이트에 적용

두 WOFF2 파일을 서비스의 `/fonts/` 경로에 배치하고 다음 CSS를 적용합니다. 파일 경로는 실제 배포 구조에 맞게 바꾸세요.

~~~css
@font-face {
  font-family: "GaDoc Sans";
  src: url("/fonts/GaDocSans-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "GaDoc Sans";
  src: url("/fonts/GaDocSans-Bold.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
body, button, input, textarea, select {
  font-family: "GaDoc Sans", system-ui, sans-serif;
  font-synthesis: none;
}
body { font-size: 16px; font-weight: 400; line-height: 1.6; }
h1, h2, h3, strong, b, .menu-item[aria-current="page"] {
  font-weight: 700;
}
~~~

`font-display: swap`은 실제 서비스에서 글꼴을 받는 동안 대체 글꼴로 먼저 표시하는 설정입니다. 위 미리보기의 로드 확인 방식과는 다릅니다.
기존 컴포넌트나 테마가 별도 `font-family`를 지정했다면 그 설정도 함께 바꿔야 합니다. 이 패키지 자체가 운영 사이트를 수정하지는 않습니다.

## 권장 시작값

| 용도 | 크기 | 굵기 | 줄 간격 |
|---|---:|---:|---:|
| 대화·문서 본문 | 16px | 400 | 1.6 |
| 기본 메뉴·버튼 | 14–16px | 400 | 1.4–1.5 |
| 선택된 메뉴·강조 | 14–16px | 700 | 1.4–1.5 |
| 소제목 | 20–24px | 700 | 1.35–1.45 |
| 페이지 제목 | 28–32px | 700 | 1.2–1.3 |

실제 화면의 긴 한글 문장, 숫자, 줄바꿈, 입력창에서 읽어 보고 조정하세요. 모든 운영체제와 브라우저에서 동일하게 보인다는 보장은 하지 않습니다.

## 출처와 라이선스

Fredoka와 LINE Seed의 OFL 기반 파생 폰트입니다. 원본 저작권·라이선스 고지와 변경 내역은 패키지의 라이선스·출처 문서를 확인하세요.
재배포할 때는 동봉한 원본 저작권 고지와 OFL 안내를 함께 유지하세요. 폰트 자체를 독점적인 비공개 라이선스로 다시 지정하는 자료는 아닙니다.
시안의 다섯 글자 외의 모든 글자를 이미지에서 복원한 폰트, 또는 원본 제작사가 출시한 공식 GaDoc 서체로 설명하지 마세요.
