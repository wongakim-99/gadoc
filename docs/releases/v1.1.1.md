- 채팅과 스레드 사진을 자르지 않고 표시하며, 대화를 벗어나지 않는 미리보기를 추가했습니다. 이전·다음 사진, 원본 크기, 다운로드, Esc 닫기를 지원합니다.
- 스레드 원문과 답글에서 첨부파일이 누락되던 문제를 수정했습니다.
- 동영상·음성 재생 버튼이 파일 링크를 열지 않도록 분리했습니다. 비공개 첨부 다운로드는 앱의 로그인 상태를 유지하며 채팅 화면을 대체하지 않습니다.
- macOS 창 버튼이 로고와 겹치지 않도록 기본 제목 표시줄을 복원했습니다. 닫으면 백그라운드에 유지하고, Dock에서 다시 열거나 Cmd+Q로 종료하는 동작은 유지됩니다.

사진 표시 개선은 웹에도 적용됩니다. macOS 창 버튼 수정은 1.1.1 앱 설치가 필요합니다.
