## 2026-10-28 후속 회귀 수정

사용자는 테스트 최소 수정을 허용했으며, 기존 우려는 코드 게시가 아니라 API 요청 집중에 따른 429였다. 인증 fixture와 브라우저 로그인은 단일 큐의 최소 650ms 간격으로 조절하고 기존 Retry-After 처리를 유지한다. 웹/API 주소 모두 확인해 원격 fixture 생성에는 명시적인 opt-in을 요구한다. 서버의 인증 제한을 올리거나 끄지 않았다.

삭제한 생성 폼, 워크스페이스 전환, 사용자 메뉴, 활성 분할창 기준 탐색에 맞춰 기존 시나리오를 수정했다. 회귀 중 알림/연결 메뉴의 겹침, 메시지에서 마우스를 옮길 때 연결 메뉴가 사라지는 현상, DB 전체 페이지 열기 경로를 함께 수정했다. 초안 보호 검증은 유지했다.

후속 검증: 인증 7 + 브라우저 35 = 서로 다른 42개 시나리오가 분할 실행 및 실패 항목 재실행 후 통과했다. 한 번의 전체 suite 통과 수치가 아니다. 웹 TypeScript와 웹 단위 105개도 통과했다. 로컬 파일 업로드 시나리오는 MinIO 미실행으로 실패했으며, 해당 테스트를 삭제하거나 완화하지 않았다. CI의 격리 오브젝트 저장소에서 전체 결과를 별도로 확인해야 한다.
