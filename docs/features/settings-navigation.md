# 설정 탐색

설정 페이지는 워크스페이스 기본 메뉴 옆에 두 번째 사이드바를 만들지 않습니다. 기존 사이드바의 탐색 부분을 개인 설정과 워크스페이스 설정으로 전환하고, 오른쪽에는 선택한 설정 내용만 표시합니다.

워크스페이스 전환, 검색, 계정 메뉴와 알림 진입점은 유지합니다. `워크스페이스로 돌아가기`를 누르면 현재 워크스페이스 홈으로 돌아갑니다. 기존 사이드바 접기 설정은 설정 화면에서 임시로 무시할 뿐 덮어쓰지 않습니다.

모바일에서는 상단의 탐색 버튼 하나로 설정 목록을 열고, 항목을 선택하면 목록이 닫혀 설정 내용을 볼 수 있습니다. 선택한 항목은 기존 `section` URL에 남아 새로고침과 직접 접근에도 유지됩니다. 기존의 섹션 없는 주소는 전달과 연동을 계속 엽니다.

`settings-navigation.e2e.spec.ts`는 사이드바가 한 개만 존재하는지, 설정 전체 전환, 새로고침, 접기 설정 복원, 모바일 메뉴 닫기와 워크스페이스 전환을 검증합니다. 계정 이메일·테마·권한·외부 연동 기능은 기존 테스트로 함께 회귀 검증합니다.

이 변경은 탐색 구조만 다룹니다. 워크스페이스별 알림 수신 정책과 채널별 예외 설정은 별도 기능이며 메뉴 통합만으로 구현됐다고 처리하지 않습니다.
