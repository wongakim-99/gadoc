# 데이터베이스 속성 표시

숫자·수식·롤업 속성은 숫자, 천 단위 구분, 퍼센트, KRW/USD/EUR/JPY/GBP/CNY 통화 형식을 지원한다. 표시 형식은 저장된 숫자나 수식·필터·CSV 원본 값을 변환하지 않는다. 예를 들어 저장값 0.5는 퍼센트 형식에서 50%이며 편집 중에는 0.5가 보인다.

선택·다중 선택·상태의 옵션은 색상과 순서를 설정할 수 있다. 옵션 핸들을 끌거나 위/아래 방향키로 이동한다. 표 태그, 선택 목록 순서, 보드 그룹의 순서와 색상에 적용된다. 사용 중인 옵션의 삭제는 기존 데이터 보호 규칙을 유지한다. 셀에서 새 옵션을 추가해도 기존 옵션 색상을 보존한다.

색상은 허용된 enum으로 검증하며 임의 CSS를 저장하지 않는다. 옵션 이름에 점이나 특수문자가 있어도 Mongo 필드 경로로 쓰이지 않도록 색상 메타데이터는 배열로 저장한다. 옵션은 고정 ID와 표시 이름을 분리한다. 속성 설정에서 이름을 변경하면 기존 셀·템플릿·이슈 DB 사용자 속성·롤업은 새 이름으로 표시하며 ID를 유지한다. 과거 이름을 새 옵션에 재사용해도 기존 선택은 새 옵션으로 옮겨지지 않는다. 상태 그룹 구현 상태와 제한은 아래 후속 항목에 기록한다. 모든 통화 종류와 로케일 설정은 아직 지원하지 않는다.

검증: 숫자 표시 단위 검사, 숫자 형식 저장/편집/재접속 및 원본 계산값 보존 E2E, 옵션 색상/키보드·드래그 순서/재접속/새 옵션 추가 후 보존 E2E. 검증용 데이터는 로컬 API fixture만 사용한다.

운영 추적: 숫자 표시 6ae1be887bd0144ab33fd01e, 옵션 표시 6ae1c1e67bd0144ab33fd045. CI·병합·운영 배포 확인 전에는 완료로 표시하지 않는다.


## 숫자 진행률 표시

숫자·수식·숫자 결과를 내는 롤업에서 막대 또는 원형 표시를 선택할 수 있다. 기준값은 양의 유한 숫자이며, 표시 비율만 0–100%로 제한한다. 저장된 음수나 기준값을 초과한 값, 수식 결과는 그대로 유지한다. 색상과 숫자 함께 표시 여부를 설정할 수 있고, 숫자 셀에 포커스하면 원래 값을 편집한다. 빈 값은 진행률 0으로 바꾸지 않는다. 별도 애니메이션은 없다.

참조: [Notion 숫자 막대/원형 표시 공식 안내](https://www.notion.com/releases/2022-08-11).
운영 추적: 6ae1d9a21f7e36dbde07fb32. 로컬 빌드/타입 검사, 경계값 및 DTO 검증 통과. 실제 API E2E는 CI에서 검증하며 통과와 배포 확인 전에는 완료 처리하지 않는다.

## 옵션 ID 저장 호환성

기존 문자열 저장값은 최초 이름에 해당하는 legacyName으로 읽는다. 신규 쓰기는 내부 ID를 저장하며 일반 셀 API 응답·CSV·수식에는 표시 이름을 사용한다. 새 고급 필터 선택은 ID를 저장하고, 기존 저장 필터는 최초 이름을 해석한다. 같은 과거 이름을 재사용한 옵션을 API 필터로 명확하게 지정하려면 optionIdentities의 ID를 사용한다.

스키마 변경은 revision 충돌 검사를 통과해야 한다. 옵션 이름 변경은 행을 일괄 덮어쓰지 않고 메타데이터를 변경하므로 각 행의 선택·수정 버전을 유지한다. ID 저장이 시작된 뒤 구버전 서버로 단순 롤백하면 내부 ID를 표시할 수 있으므로 이 호환 코덱을 유지해야 한다. 운영 데이터 일괄 변환은 실행하지 않는다.

추가 검증: 이름 변경·색상 보존·과거 이름 재사용·중첩 필터, 템플릿 상태·이슈 다중 선택, stale revision과 guest 거부. 전체 Notion 동등성이나 상태 그룹·속성 유형 변환 완료를 뜻하지 않는다.


## 상태 그룹

상태 속성은 할 일·진행 중·완료의 세 범주와 그 아래 세부 옵션을 가진다. 속성 편집에서 각 옵션의 범주를 지정하고, 셀 목록에서 범주별로 선택한다. 소속은 옵션 ID로 저장하므로 이름을 바꿔도 유지된다. 의미가 알려지지 않은 기존 상태는 임의로 완료 처리하지 않고 할 일 범주로 읽는다.

보드는 옵션별/그룹별 표시를 선택하며 보기와 함께 자동 저장한다. 그룹으로 카드를 이동하면 해당 그룹에서 첫 번째 옵션을 선택한다. 옵션이 없는 그룹으로는 이동하지 않으며, 원본 이슈 상태 속성은 기존 수정 권한 규칙을 유지한다.

참조: [Notion 상태 속성 공식 안내](https://www.notion.com/help/guides/status-property-gives-clarity-on-tasks).
운영 추적: 6ae1dd761f7e36dbde07fd84. core 3개/server 19개와 빌드·타입 검사 통과. 실제 API E2E와 배포 검증은 진행 중이다. 전체 Notion 상태 필터·기본값·시각 동등성 완료를 의미하지 않는다.


## 상태 그룹 필터 후속

상태 속성의 고급 필터에서 그룹이 같음/다름을 선택한다. 범주 키는 옵션 식별자와 별도로 보존하므로 옵션 이름 변경이나 같은 이름의 옵션 재사용에 영향을 받지 않는다. 비어 있는 값은 특정 그룹과 같지 않으며, '그룹이 다름'에는 포함된다. 조건은 기존 AND/OR 중첩 필터·저장된 보기에 적용한다.

긍정 AND 그룹 조건으로 새 페이지를 만들면 해당 그룹의 첫 옵션을 기본값으로 사용한다. 더 구체적인 양립 가능한 상태 조건은 우선하며 모순되는 그룹 조건이나 OR 조건은 값을 추측하지 않는다. core 조회 11개 및 기본값 5개 검증 통과, 실제 API E2E/배포 확인은 남아 있다.


## 상태 체크박스 표시 후속

일반 상태 속성과 이슈 소스 사용자 정의 상태 속성은 선택 목록/체크박스 표시를 설정할 수 있다. 체크박스는 완료 범주이면 체크, 진행 중이면 중간 상태, 할 일이면 해제로 표시한다. 체크 시 완료 범주의 첫 옵션, 해제 시 할 일 범주의 첫 옵션을 저장하며 원본 상태 문자열·ID 계약을 유지한다. 전환할 옵션이 없으면 비활성화한다. 이슈 기본 속성의 구조 변경 제한은 유지하므로 해당 속성 표시 변경은 아직 제공하지 않는다.

기존 GaDoc 기본 옵션 '검토 중'은 진행 중, '게시됨'·'보관'은 완료로 해석한다. 사용자가 명시적으로 저장한 그룹 소속은 우선한다. 서버·core 검증 및 타입 검사 통과, 실제 API E2E와 배포는 진행 중이다.


## 보드 빈 그룹과 카드 크기
- 보기 옵션에서 빈 그룹 숨기기와 작게/보통/크게 카드 크기를 선택한다. 인라인 및 저장된 보기마다 유지한다.
- 빈 그룹 숨김은 행을 삭제하지 않으며 끄면 빈 그룹이 다시 나타난다. 데이터가 있는 그룹은 계속 보인다.
- 사용자 지정 그룹 숨김·복원 및 그룹 열 순서, 하위 그룹, 이미지 미리보기는 아직 별도 미구현 항목이다.
